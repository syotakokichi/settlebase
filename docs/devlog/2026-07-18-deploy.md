## 環境変数・キーの扱い

- 使用したのは `NEXT_PUBLIC_SUPABASE_URL` と `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` の 2 つのみ。
  publishable key はクライアントに埋め込まれる公開前提のキー
- secret / service_role キーはどこにも記録・使用していない（コミット・クライアント使用とも禁止）
- `.env` 系はコミットしない（`.env.example` のみ追跡）。実値は Vercel の環境変数で管理

## keep-alive 判断

Supabase 無料枠は 7 日間低活動でプロジェクトが一時停止（pause）される。

- **判断: pause は受容する（keep-alive はしない）**
- 理由: 本リポジトリはデモ用途でアクセスは連載執筆・公開のタイミングに集中する。
  pause されてもダッシュボードから数分で再開できる。
  自動 ping 等の keep-alive は「必要になった時に利用規約を確認した上で」再判断する
